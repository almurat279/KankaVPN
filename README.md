# Kanka VPN
Basit Android WireGuard VPN istemcisi.

## Ne yapar?
- Telefonda `.conf` WireGuard yapılandırması seçer.
- Android VPN iznini ister.
- Tek tuşla bağlanır / bağlantıyı keser.
- WireGuard'ın resmi Android tunnel kütüphanesini kullanır.

## Önemli
Bu proje VPN sunucusu sağlamaz. Çalışan bir WireGuard sunucusundan aldığınız `.conf` dosyası gerekir.

## APK oluşturma
Projeyi Android Studio'da açın, Gradle senkronizasyonunu bekleyin ve Build > Build APK(s) seçin.
